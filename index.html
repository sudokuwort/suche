      Anleitung zum Überdrucken vorbereiteter Blätter

      1. Drucken Sie zuerst Blatt 1 (Arbeitsblatt) als Vorlage auf Papier aus.
      2. Legen Sie das bedruckte Blatt passgenau (gleiche Oberkante) wieder in das Papierfach Ihres Druckers ein.
      3. Wählen Sie im Druckdialog zwingend „Tatsächliche Größe“ (100 % Skalierung) ohne „An Seite anpassen“, damit die Lösung exakt in die Felder gedruckt wird.
      4. Nutzen Sie die Blatt-1-Hilfslinien im Vorschaufenster zur visuellen Lagekontrolle — diese Hilfslinien werden nicht mitgedruckt.
